# Iowa ALICE Resource Hub

One place for Local United Way staff across Iowa to find, understand and use ALICE resources, and to tell us what they need.

Maintained by United Way of East Central Iowa. Statistics come from [United For ALICE, Iowa](https://www.unitedforalice.org/introducing-ALICE/iowa) (2024 data, 2026 release).

## Publishing with GitHub Pages

1. Upload `index.html` (and this README) to the root of a repository.
2. Go to **Settings > Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, and save.
3. The site will be live at `https://<your-username>.github.io/<repo-name>/` within a few minutes.

## Editing

Everything is in `index.html`: styles in `<style>`, pages as `<div class="page" id="p-...">` blocks, and the Resource Library data in the `LIB` array near the bottom of the file. Pages are linked by hash (for example `#alice-101`, `#library`).
